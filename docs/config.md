# Переменные окружения

Всё, что нужно серверу, читается из окружения **один раз, на старте**. Отсутствующее значение — отказ
запуститься, а не запрос, падающий в три часа ночи.

## API

| Переменная | Обязательна | По умолчанию | Что это |
| --- | --- | --- | --- |
| `DATABASE_URL` | да | — | PostgreSQL 17, прямое подключение или session-режим. |
| `TELEGRAM_BOT_TOKEN` | да | — | От BotFather. Проверяет каждый запрос и отправляет каждое сообщение. |
| `BIND` | нет | `0.0.0.0:8080` | Адрес, который слушать. |
| `DATABASE_MAX_CONNECTIONS` | нет | `16` | Размер пула подключений, **на процесс**. |
| `PUSTOL_ASSETS_DIR` | нет | — | Собранные файлы приложения (`web/out`). Без неё приложение отдаётся откуда-то ещё. Указана неверно — падение на старте, а не белый экран на телефоне гостя. |
| `RUST_LOG` | нет | `info,pustol_api=debug` | Фильтр логов. |

## Создание бара

| Переменная | Обязательна | Что это |
| --- | --- | --- |
| `DATABASE_URL` | да | То же, что выше. |
| `TELEGRAM_ADMIN_USERNAME` | да | Ник первого админа в Telegram, с `@` или без. |

Используются только командой `cargo run -p pustol-api --bin seed`.

## Веб-приложение

Живут в `web/.env.local`, образец — `web/.env.example`.

| Переменная | Обязательна | Что это |
| --- | --- | --- |
| `PUSTOL_API_URL` | только в разработке | Куда `next dev` проксирует `/api`. По умолчанию `http://127.0.0.1:8080`. |
| `NEXT_PUBLIC_BOT_USERNAME` | да | Ник бота, без `@`. Нужен, чтобы открыть чат с ботом. |
| `NEXT_PUBLIC_DEV_INIT_DATA` | нет | Подписанные данные Telegram для работы вне Telegram. Только локально. |

## Кеширование собранного приложения

API отдаёт экспорт с двумя политиками, потому что в экспорте два вида файлов:

- `_next/static/**` имеет хеш в имени, поэтому кешируется на год — но только когда было что отдать.
  404, пойманный в середине выкладки, не должен запомниться на год клиентом, до которого новая сборка
  уже не дотянется.
- Всё остальное перепроверяется. `index.html` называет файлы с хешами, и его устаревшая копия
  переживает сборку, которая эти файлы удалила, оставляя белый экран в окне Telegram, которое гость не
  может обновить принудительно.
