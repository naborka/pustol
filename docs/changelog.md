# Изменения

Заметные изменения, новые сверху. Формат — [Keep a Changelog](https://keepachangelog.com), версии —
[Semantic Versioning](https://semver.org).

## Unreleased

### Added

- **Компания ушла раньше.** Статус `left` возвращает стол в подбор с той минуты, когда его освободили.
  `no_show` теперь тоже возвращает — в конце времени ожидания опоздавших, а не в момент нажатия.
- **Перенести бронь.** `PATCH /api/admin/bookings/{id}/move` — новое время, новый стол или и то и
  другое. Меняется время — гостю уходит сообщение, напоминание переезжает следом. Меняется только
  стол — гость ничего не узнаёт. Начавшаяся бронь время не меняет: это уже история вечера.
- **Стол выбирает персонал.** «Посадить сейчас» и «Записать гостя» показывают все свободные столы, а
  не один. `POST /api/admin/walkins` и `POST /api/admin/bookings` принимают `table_id`; без него
  стол по-прежнему выбирает зал. Выбранный стол проверяется по тому же списку, из которого выбирает
  аллокатор, и в той же транзакции.
- **Гости с улицы.** `POST /api/admin/walkins` сажает компанию той минутой, когда она села, а не
  ближайшим шагом сетки. Итоги смены честны только с ними.
- **Заметка на брони.** `PATCH /api/admin/bookings/{id}/note`, до 120 знаков, никогда не уходит гостю.
- **Полоса вечеров.** `GET /api/days?party_size=` — ровно горизонт бронирования, выходные включительно,
  каждый день говорит, с какого времени свободен.
- Смена отдаёт `largest_party_seatable_now` и месяц вперёд со счётчиком броней на каждый вечер.
- Container image `ghcr.io/naborka/pustol` (`:sha-<git>` immutable, `:prod` moving). One process, one origin.
- `.github/workflows/release-api.yml` builds the image and SSHes the unit name `pustol`. Rollback retags `:prod`.

### Fixed

- **Имя гостя снова можно набрать.** Панель забирала фокус на каждую перерисовку, и клавиатура
  закрывалась после первой буквы. Фокус теперь ставится один раз — при открытии.
- **Вечер, который уже прошёл, больше не предлагают.** Гость, которого персонал отметил как ушедшего,
  до конца обещанного окна видел «Стол ваш» с кнопками «Перенести» и «Отменить». Бронь у гостя живёт
  ровно столько, сколько бар держит стол, — по тому же `occupancy`, что и всё остальное. То же и для
  `no_show`, с конца времени ожидания опоздавших.

### Changed

- **Одно правило занятости.** Стол занят от начала брони до `released_at`, и из этого выведено всё:
  свободные столы, времена для гостя, предложение гостям с улицы, ширина блока на таймлайне,
  занятость в итогах.
- **Смена — три вида:** «Сейчас» (список, который сам отвечает на все вопросы вечера), «Столы»
  (таймлайн), «Итоги» (чек смены). Посадить и отметить уход — одно нажатие с отменой.
- **Гость выбирает вечер по полосе**, где каждый день говорит, что у него есть. Отмена идёт через
  подтверждение и шесть секунд предлагает вернуть бронь.
- **Настройки — список из шести разделов**, в каждой строке её текущее значение.
- **Приложение чинится внутри Telegram:** высота из `viewportStableHeight`, ровно один прокручиваемый
  элемент, панели внутри оболочки, вертикальный свайп больше не сворачивает приложение, у каждого
  элемента есть нажатое состояние, в табах слова вместо глифов.
- Палитра по умолчанию проходит контраст 4.5:1 против фона и карточки в обеих схемах.
- SIGTERM drains the outbox the same way SIGINT already did. Containers send SIGTERM by default.
- Static files are no longer pre-gzipped. Caddy encodes.

## 0.1.0 — 30 июля 2026

Первый выпуск. Бронирование столов для одного бара из Telegram Mini App.

### Добавлено

- **Гости** бронируют в три нажатия — компания, вечер, время — и сразу видят подтверждение. Одна живая
  бронь за раз, повторная бронь её заменяет, отмена — одно нажатие. По желанию бот напомнит, с
  кнопкой отмены прямо в сообщении.
- **Персонал** ведёт смену с телефона: таймлайн или список, живые счётчики, пришли / не пришли,
  готовые сообщения, отмена с причиной, о которой сообщат гостю, брони у двери и закрытие стола на
  вечер.
- **Управляющие** задают часы работы по дням недели, зал, правила бронирования, точные сообщения для
  персонала и сам список персонала. Недопустимые изменения гаснут до нажатия; сохранение, которое
  оставило бы бронь без места, отклоняется с перечислением этих броней.
- **Бронь — всегда конкретный стол**, выбранный одним аллокатором, общим для экрана выбора, формы
  персонала и пересадки. «Подтверждено, но сесть некуда» не имеет представления в системе.
- **Стол нельзя продать дважды**: это держит ограничение `EXCLUDE` в PostgreSQL, а не код приложения.
  Проверяется гонкой восьми гостей за один стол.
- **Вечера, уходящие за полночь**, — одна смена. Часы работы — факт по настенным часам, пересечение
  судится по настоящему времени. Время, через которое перепрыгнули стрелки, не предлагается.
- **Очередь для всего, что отправляет бот.** Решение транзакционно, доставка нет; заблокированный бот
  не повторяется, ограничение частоты соблюдается точно.
- **Данные Telegram живут час**, а права даёт числовой аккаунт, а не ник.
- **Один процесс отдаёт API и приложение**, поэтому источник один — потому что слушатель один.
- **Никакое решение о хостинге не зашито в проект.** Пустол — это бинарник плюс каталог статических
  файлов; где он работает, решает тот, кто его ставит.
- **Схема лежит в `migrations/`** и применяется на старте и тестами из одного места, поэтому база и
  код, который с ней разговаривает, не могут разойтись.
- **`scripts/pg.sh` работает и на musl, и на glibc.** Он выбирает сборку под машину, достаёт без root
  библиотеки времени выполнения и базу часовых поясов и не требует Python: нужны `unzip` и `curl`
  либо `wget`.
- **Эта документация** — книга mdbook на русском языке, публикуется на GitHub Pages.
- 348 тестов: 272 в Rust, 76 в приложении. Доменные тесты проверены мутациями.
