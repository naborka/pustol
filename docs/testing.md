# Тесты

549 тестов: **318 в Rust**, **231 в приложении**.

```bash
scripts/pg.sh start                      # тестам базы нужен настоящий PostgreSQL
export DATABASE_URL="$(scripts/pg.sh url)"

cargo test --workspace
cargo clippy --workspace --all-targets

cd web && npm test && npm run typecheck
```

## Почему настоящая база

Правило, на котором держится вся система, — стол нельзя продать дважды — обеспечивает ограничение
`EXCLUDE` в PostgreSQL. Проверять его на подделке значит не проверять ничего. Поэтому тесты базы
работают с настоящим PostgreSQL 17, который `scripts/pg.sh` достаёт без root, контейнера и пакетного
менеджера.

Каждый тест базы создаёт себе отдельную базу. Очередь сообщений не разделена по барам, поэтому
параллельные тесты в одной базе забирали бы сообщения друг друга.

## Две вещи о том, как они написаны

**Доменные тесты проверены мутациями.** Best-fit меняли на first-fit, полуоткрытые интервалы на
закрытые, выбрасывали фильтр «уже закончилось» — и каждую такую мутацию ловит тест, в имени которого
написано, что он защищает.

**В фикстурах намеренно фиксированные идентификаторы.** Со случайными UUID проверка порядка проходит
или падает по удаче, а это хуже, чем никакой проверки.

## Самый важный

`crates/pustol-db/tests/bookings.rs` устраивает гонку восьми гостей за один стол и требует, чтобы
выиграл ровно один. Не «обычно один», а ровно один, каждый запуск.
