# Справочник API

Один процесс отдаёт и API, и приложение. Всё под `/api` — JSON, всё остальное — файлы приложения.

## Аутентификация

Каждый запрос к `/api` несёт данные, которые Telegram выдал Mini App:

```http
Authorization: tma <initData>
```

Они проверяются токеном бота и отклоняются, если старше **часа**. Приложение обновляет их при каждом
запуске, так что гостю это ничего не стоит.

Аутентификация ничего не говорит о правах. Точки под `/api/admin` сверяют **числовой аккаунт**
Telegram со списком персонала бара — никогда ник, который владелец может освободить, а посторонний
занять.

## Гостевые точки

| Метод | Путь | Что делает |
| --- | --- | --- |
| `GET` | `/api/session` | Всё для первого экрана одним запросом: кто вы, бар, ваша бронь, какие вечера открыты, с какого времени свободно сегодня. |
| `GET` | `/api/days?party_size=` | Вся полоса вечеров: по одному на каждый день горизонта бронирования, с первым свободным временем, `выходной` или «мест нет». |
| `GET` | `/api/availability?service_date=&party_size=` | Времена прихода для такой компании в такой вечер. |
| `POST` | `/api/booking` | Взять бронь. Тело: `service_date`, `start_minutes`, `party_size`. Заменяет прежнюю бронь, если та ещё не началась, и сообщает какую. |
| `DELETE` | `/api/booking` | Вернуть стол. Гостю ничего не отправляется. |
| `POST` | `/api/reminders/opt-in` | Попросить у бота напоминания. |
| `POST` | `/api/reminders/dismiss` | «Не сейчас» — запоминается, чтобы спросить один раз. |

`start_minutes` — минуты по настенным часам от полуночи дня смены. Бронь на 01:00 в ночь с пятницы —
это `1500`, и она пятничная.

Полоса вечеров — ровно `horizon_days` записей, выходные включительно. День, на который бар закрыт,
приходит с `closed: true`, а не выбрасывается: полоса, молча теряющая понедельники, каждую неделю
была бы разной длины, и гость гадал бы, куда делся понедельник.

## Точки для персонала

Все под `/api/admin`, все требуют, чтобы вызывающий был в списке персонала.

| Метод | Путь | Что делает |
| --- | --- | --- |
| `GET` | `/shift?service_date=` | Весь вечер: столы, брони, счётчики, где проходит «сейчас», кого сейчас можно посадить и список из 30 вечеров вперёд. |
| `POST` | `/shift/reconcile` | Попробовать посадить брони, оставшиеся без стола. |
| `GET` | `/availability?service_date=&party_size=` | Те же времена, что предложили бы гостю, но без горизонта бронирования. |
| `POST` | `/bookings` | Взять бронь по телефону. В теле добавляется `guest_name`. |
| `POST` | `/walkins` | Посадить гостей с улицы: `service_date` и `party_size`. Только на идущей смене; время прихода — текущая минута, а не ближайший шаг сетки. |
| `PATCH` | `/bookings/{id}/attendance` | `confirmed`, `arrived`, `no_show` или `left`. Отмена — намеренно другая точка. |
| `PATCH` | `/bookings/{id}/note` | Заметка персонала, до 120 знаков, или `null`, чтобы стереть. Гостю не уходит никогда. |
| `POST` | `/bookings/{id}/cancel` | Освободить стол с `reason` из списка бара. Гостю сообщат. |
| `POST` | `/bookings/{id}/message` | Отправить одно из сообщений бара. Свободный текст не принимается. |
| `POST` | `/blocks` | Закрыть столы на вечер, с причиной. |
| `DELETE` | `/blocks` | Открыть их обратно. |
| `GET` | `/settings` | Текущие настройки и границы, которые должен соблюдать каждый элемент. |
| `PUT` | `/settings` | Сохранить. При недопустимости отказ с названными причинами или со списком броней, которые остались бы без места. |

## Ошибки

Отказ приходит со стабильным **кодом** и английской фразой для лога. Слова, которые читает человек,
живут в приложении, — поэтому правка запятой в русском тексте не требует релиза бэкенда.

```json
{ "code": "no_table_free", "message": "...", "detail": { "party_size": 4 } }
```

| Код | Что значит |
| --- | --- |
| `no_credentials` | В запросе нет данных Telegram. |
| `not_telegram` | Данные подписаны не Telegram. |
| `session_expired` | Данные старше часа или подписаны будущим временем. |
| `forbidden` | Аутентифицирован, но не в списке персонала. |
| `not_found` | Нет такой брони, стола или точки. |
| `not_an_arrival_time` | Бар не принимает приход в это время. |
| `in_the_past` | Это время уже прошло. |
| `impossible_time` | Такого времени в эту дату не существует. |
| `no_table_free` | Все столы, куда влезла бы эта компания, заняты или закрыты. |
| `party_too_large` | Больше предела бара. |
| `shift_not_bookable` | В этот день закрыто или это вне горизонта бронирования. |
| `blank_guest_name` | Бронь у двери без имени, на которое звать. |
| `missing_block_reason` | Стол нельзя закрыть, не сказав почему. |
| `unknown_cancel_reason` | Не из списка причин бара. |
| `unknown_message` | Не из списка сообщений бара. |
| `no_bot_chat` | У гостя нет чата с ботом, отправить нечего и некуда. |
| `note_too_long` | Заметка длиннее, чем помещается в строку списка. |
| `not_the_running_shift` | «Сейчас» просят на вечере, который не идёт. |
| `settings_invalid` | В `detail.reasons` перечислено, что не так. |
| `settings_unreadable` | Черновик не совпадает с текущим залом. Перезагрузите. |
| `would_strand_bookings` | В `detail.conflicts` названы мешающие брони. |
| `unknown_timezone` | Нет такого часового пояса. |
| `internal` | Что-то сломалось на нашей стороне. |

Запросы ограничены **64 КБ**: самое большое, что кто-либо присылает, — сохранение настроек, а это
несколько килобайт.

## Когда стол снова свободен

У брони два времени конца, и они разные.

`end_minutes` — конец окна, обещанного гостю. Он не укорачивается никогда: что бар пообещал, тем и
остаётся, что бы ни случилось вечером.

`released_minutes` — минута, когда стол вернулся в общий подбор. Он появляется, когда компания ушла
раньше (`left` — момент нажатия) или не пришла (`no_show` — конец времени ожидания опоздавших, а не
момент, когда бармен спохватился). До этой минуты стол занят, с неё — свободен.

Отсюда считают всё: `stats.free_now`, времена для гостя, предложение для гостей с улицы, ширина
блока на таймлайне и занятость столов в итогах. Одно правило — поэтому экран не может показывать
занятым стол, который сервер уже продал кому-то другому.

Возврат в `arrived` или `confirmed` стирает `released_minutes`, так что отмена действия возвращает
зал ровно туда, где он был.
